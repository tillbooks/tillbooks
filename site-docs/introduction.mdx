TILL (Trusted Independent Ledger Library) is Swiss accounting software you own. It is MIT licensed,
it runs on your machine, and your books live in a single SQLite file you can copy, back up, and read
without asking anyone's permission.

It is built agent-first. The MCP server is a real interface, not an AI feature bolted onto a GUI, so
an agent can post entries, draft invoices, and prepare the MWST-Abrechnung directly. The Studio GUI
exists so a human can oversee that work.

## Status

Pre-alpha. The capability specs are written and the ledger core is in progress. Nothing here is
ready for real books yet.

## What TILL is built for

Switzerland, specifically:

- Swiss QR-bill (QR-Rechnung) with the structured-address standard
- MWST at 8.1%, 3.8% and 2.6%, and the MWST-Abrechnung
- Kontenrahmen KMU, seeded out of the box
- ISO 20022 (camt/pain) banking

TILL is an independent clean-room project. It is not affiliated with bexio AG.
