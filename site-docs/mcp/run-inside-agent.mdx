---
title: "Run TILL inside an agent"
description: "Use TILL with zero installed infrastructure, and the three trade-offs to know first."
---

You do not need a machine of your own for TILL. If you already work in an agent runtime (Claude
Desktop on your Mac, or a Claude Code / Cowork session in the cloud), TILL runs inside it. The
public beta is on npm as `tillbooks@beta`, so the session needs Node.js 22 or newer and nothing
else. Register the MCP server with `TILL_DB_PATH` pointing at a `.db` file in the session folder,
and the full verb surface works: the engine has no idea it is sandboxed, and tenancy, the approval
dial and the permission model hold exactly as they do anywhere else.

Register the server, do not start it in the shell: a stdio server you start by hand talks to your
terminal, not to the agent. The agent starts it when it needs it. In Claude Code, from the session
folder (the shell fills in the folder once, so the stored path is absolute):

```bash
claude mcp add tillbooks -e TILL_DB_PATH="$PWD/till.db" -- npx -y tillbooks@beta mcp
```

Any other client takes the same server with an `env` block, for example in a `.mcp.json` in the
session folder. Put the absolute path of the session folder in `TILL_DB_PATH`:

```json
{
  "mcpServers": {
    "tillbooks": {
      "command": "npx",
      "args": ["-y", "tillbooks@beta", "mcp"],
      "env": { "TILL_DB_PATH": "/absolute/path/to/the/session/folder/till.db" }
    }
  }
}
```

To tell TILL it is running this way, set one more variable on the same registration. TILL never
guesses it: add `-e TILL_RUNTIME_MODE=agent_session` to the `claude mcp add` line, or
`"TILL_RUNTIME_MODE": "agent_session"` to the `env` block.

With the flag set, `delivery_status` reports `mode: agent_session`, and the Studio shows the
residency note below. This is the honest signal that the trade-offs on this page apply.

## Three things to know first

This mode is real and supported. It also gives up three things a local install keeps, and TILL says
so rather than hiding them.

### 1. Residency

A cloud agent session runs on the vendor's machine, not yours. So while you work this way, "your
books never leave your machine" does not hold: the data lives on that machine for the length of the
session. A local Claude Desktop session keeps full residency, because it runs on your own Mac. This
mode makes no promise about Swiss data residency. TILL offers no hosted version today; a
Swiss-hosted one is planned for later.

### 2. Local correspondence is off in the cloud

The mail, drafting and voice features read your local mail store and run a local model on Apple
Silicon. A cloud machine has neither, and TILL will not host them for you by design. In cloud agent
mode these verbs return `needs_local_runtime` rather than a stand-in. Run them on a local Mac, or not
at all.

### 3. Back up at the end of every session, and carry the file out

A session folder is disposable. Treat the backup as a ritual, not as optional hygiene: a ledger whose
only copy lives in a machine that will be wiped is not a ledger.

```bash
# at the end of the session: take a backup and move the file OUT of the sandbox
create_backup
# carry the .tillbackup out through the session's own file transfer, then next session:
restore_backup   # or point TILL_DB_PATH at the file you carried back in
```

TILL does not take backups for you, here least of all. A runtime can vanish between one message and
the next, and the books go with it unless you carried the backup out.

## The one-click extension (not available yet)

TILL is designed to ship a `.mcpb` desktop extension for Claude Desktop, so that installing `till mcp`
is one double-click with no JSON to edit. The extension manifest is defined: it exposes exactly two
settings, the database path and the support directory, and it bundles no database of its own.

It is not available to install yet, because the bundle has not been packed or published. It is
planned as a release asset beside the npm package. Until then, use the JSON configuration in the
[quickstart](/quickstart#connect-an-agent). The [agent interface overview](/mcp/overview) describes
the verb surface either way gives you.
